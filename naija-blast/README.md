# Naija Blast

A 3D Nigerian marble shooter: 100 sectors, ten bosses.

The game is a single static file in `public/index.html`.

## Deploy on Cloudflare

Workers (current dashboard flow):
- Root directory / path: `naija-blast`
- Build command: empty
- Deploy command: `npx wrangler deploy`
- Branch: `claude/sleepy-noether-vy71oq`

Pages (legacy flow):
- Build command: empty
- Build output directory: `naija-blast/public`
